# ER Studio | AI Database Architect 🚀

![ER Studio Hero Image](https://images.unsplash.com/photo-1555066931-4365d14bab8c?q=80&w=1200&auto=format&fit=crop)

**ER Studio** is a modern, full-stack web application that leverages Artificial Intelligence to instantly design, analyze, and visualize complex relational databases.

## 🌟 Features
* **AI-Powered Schema Generation:** Describe your database in plain English, and the integrated Google Gemini AI will instantly write the raw SQL definition for you.
* **Dual Visualization Engines:** Switch instantly between industry-standard **Crow's Foot Notation** (Table view) and academic **Chen's Notation** (Entity-Relationship view).
* **Smart Grid Routing:** The math-based layout engine automatically organizes massive schemas into clean, non-overlapping 2D grids, preventing infinite horizontal scrolling.
* **Cloud Sync:** Securely log in with Google OAuth 2.0 to save, load, and delete your database blueprints to the MongoDB cloud.
* **1-Click Export:** Instantly export your finished diagrams as high-resolution PNGs for presentations or documentation.
* **Template Library:** Includes 12 pre-built, industry-standard database templates (E-Commerce, Hospital Management, Video Game RPG, etc.) to get you started immediately.

## 🛠️ Tech Stack
* **Frontend:** React 18, Vite, React Flow, Google OAuth, Lucide Icons, Glassmorphism CSS.
* **Backend:** Node.js, Express, MongoDB (Mongoose), JSON Web Tokens (JWT).
* **AI Engine:** Google Gemini Pro API.
* **Deployment:** Hosted on Vercel (Frontend) and Render (Backend).
